VOTEHUB TWO-PARTY REVENUE SPLIT UPDATE
======================================

What changed
------------
1. Every event now has an Admin/VoteHub revenue percentage.
2. The default Admin/VoteHub percentage is 30.00%.
3. Client percentage is automatically calculated as 100% minus Admin/VoteHub percentage.
4. Example: Admin 30% -> Client 70%.
5. The split is applied to the event's entire successful gross revenue.
6. Pending, failed, cancelled and refunded transactions are excluded from gross revenue.
7. Each transaction stores the Admin/VoteHub percentage that was active when the transaction was created. This preserves historical financial calculations if an event's percentage is changed later.
8. Create Event and Edit Event both allow the Admin/VoteHub percentage to be changed from 0% to 100%.
9. Event View shows Gross Revenue, Admin/VoteHub amount and Client amount.
10. Transactions show Admin Share and Client Share for successful transactions.
11. Reports now show event gross revenue and the two-party distribution.

Production upgrade
------------------
If VoteHub is already installed on Hostinger, upload migrate_revenue_split.php to the VoteHub root and log in as Super Admin, then open:
https://votehubgh.org/migrate_revenue_split.php

After it reports success, DELETE migrate_revenue_split.php from the server.

For a fresh installation, database/schema.sql already contains the required columns, so no migration is required.

Important
---------
Changing an event's revenue percentage affects future transaction records. Existing transactions retain the percentage stored at the time they were created.

CLIENT CASH-OUT UPDATE
1. A client_cashouts ledger has been added.
2. Client earned revenue remains the client's percentage of successful gross revenue.
3. Client available balance is Client Earned minus cash-outs with Requested, Approved or Paid status.
4. Recording a cash-out reserves/reduces the client's available balance immediately, preventing double cash-out.
5. Paid cash-outs remain in the ledger and are included in cash-out totals.
6. Rejected/Cancelled cash-outs release the reserved amount back to the client's available balance.
7. Admin can manage cash-outs from Admin -> Client Cash-outs.
8. Event View and Super Admin Dashboard show Client Earned, Client Cash-out and Client Available amounts.
